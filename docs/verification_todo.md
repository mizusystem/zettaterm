確認用のマクロの例：

```
strdim r 2
r[0] = 'show version'
r[1] = 'show clock'
listbox '送るコマンド' '選択' r
if result >= 0 sendln r[result]
filenamebox '保存先' 1
messagebox inputstr 'filenamebox'
```
